FLOW OPEN #01

Для полного стака разница MMR не запрещает подачу заявки. Пока друзья указываются по никам вручную. Для соло укажи 0 друзей, для дуо — 1, группы из 3 — 2, из 4 — 3, полного стака — 4. Группа подаётся одной заявкой, чтобы её не разделяли при распределении.
